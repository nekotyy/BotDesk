# BotDesk

Desktop-приложение для работы с диалогами Telegram-ботов. Интерфейс сделан на React + TypeScript, desktop-оболочка и безопасный системный слой — на Electron.

## Возможности

- подключение до 15 ботов по токенам BotFather;
- проверка токена через `getMe` до сохранения;
- системное шифрование токенов через Electron `safeStorage`;
- отдельный экран выбора бота;
- список диалогов с именами, фамилиями, username, аватарками и непрочитанными;
- поиск по имени, username и Telegram ID;
- открытие доступного диалога по user ID;
- отправка сообщений от имени выбранного бота;
- локальная история входящих и исходящих сообщений;
- фоновая синхронизация новых сообщений;
- светлая и тёмная темы по настройке ОС.

## Ограничения Telegram Bot API

Telegram не разрешает боту первым начинать личный диалог. Функция открытия по ID сработает, только если пользователь уже взаимодействовал с ботом и чат доступен через Bot API.

Bot API также не отдаёт полную старую историю сообщений. BotDesk сохраняет локально все сообщения, которые получил после подключения бота, а также исходящие сообщения из приложения. При первой синхронизации Telegram обычно возвращает только накопившиеся недавние updates.

Если бот использует webhook в другом сервисе, `getUpdates` будет недоступен. Для работы фоновой синхронизации webhook нужно отключить или реализовать отдельный мост доставки updates.

## Разработка

Требования: Node.js 20+ и Windows 10/11.

```powershell
npm install
npm run dev
```

Проверки:

```powershell
npm run typecheck
npm run lint
npm run build:web
```

## Production build

```powershell
npm run build
```

Готовая portable-версия появится в `release/BotDesk-Portable-<version>.exe`. Установка не нужна: это один самостоятельный файл со всеми зависимостями внутри.

## Где хранятся данные

Состояние приложения хранится локально в каталоге Electron `userData` в файле `botdesk-state.json`. Токены не передаются никаким промежуточным серверам: запросы к Telegram выполняются непосредственно desktop-процессом приложения.
