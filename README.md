# TG Bot Manager

Desktop-приложение для управления Telegram-ботами на базе Electron + React + TypeScript.

## Что умеет

- Добавление до 15 ботов через токен + название.
- Экран выбора бота.
- Экран чатов с аватарками, юзернеймами и историей сообщений.
- Поиск/открытие диалога по user ID (если чат существует и доступен боту).
- Отправка сообщений от имени выбранного бота.
- Локальное сохранение состояния через `electron-store`.

## Экраны

1. Онбординг: приветствие, ввод токена и названия.
2. Список добавленных ботов.
3. Чаты + диалог в стиле мессенджера.

## Запуск

```bash
npm install
npm run dev
```

## Сборка desktop

```bash
npm run build
```

Результат будет в папке `release/`.

## Важное ограничение Telegram

Бот может писать пользователю только если уже есть диалог или пользователь взаимодействовал с ботом. Поэтому открытие чата по ID работает, когда Telegram API возвращает доступ к этому чату.
